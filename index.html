Учебная страница лабораторной работы № 5.

  1. Публичный репозиторий хранит исходный index.html.
  2. GitHub Pages публикует его из корня ветки main.
  3. Запись CNAME связывает учебное имя с хостом GitHub Pages.
  4. Браузер разрешает доменное имя через DNS и запрашивает страницу по HTTP или HTTPS.
